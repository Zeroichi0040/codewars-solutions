# Number of People in the Bus

A list/array of integer pairs is provided. Elements of each pair represent the number of people that get on the bus (the first item) and the number of people that get off the bus (the second item) at a bus stop.

The task is to return the number of people who are still on the bus after the last bus stop (after the last array).

[[10,0],[3,5],[5,8]])=> 5
[[3,0],[9,1],[4,10],[12,2],[6,1],[7,10]])=> 17

Keep in mind that the test cases ensure that the number of people in the bus is always >= 0. So the returned integer can't be negative.
